═══════════════════════════════════════════════════════════════
  📁 CREATE GITHUB REPOSITORY - EASY STEPS
═══════════════════════════════════════════════════════════════

Follow these exact steps to create your GitHub repository:

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
STEP 1: OPEN GITHUB AND LOGIN
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Open your browser

2. Go to: https://github.com

3. If you don't have an account:
   - Click "Sign up" (top-right)
   - Enter your email
   - Create a password
   - Choose a username (e.g., "srinidhisarees")
   - Verify your email
   
4. If you have an account:
   - Click "Sign in"
   - Enter your username/email and password

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
STEP 2: CREATE NEW REPOSITORY
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. After logging in, look at the top-right corner

2. Click the "+" icon (plus sign)

3. Click "New repository" from the dropdown

4. You'll see a form - fill it like this:

   ┌─────────────────────────────────────────────────────────┐
   │ Repository name *                                       │
   │ ┌─────────────────────────────────────────────────────┐ │
   │ │ srinidhi-sarees-website                             │ │
   │ └─────────────────────────────────────────────────────┘ │
   │                                                           │
   │ Description (optional)                                  │
   │ ┌─────────────────────────────────────────────────────┐ │
   │ │ E-commerce website for Srinidhi Sarees              │ │
   │ └─────────────────────────────────────────────────────┘ │
   │                                                           │
   │ ○ Public    ○ Private                                   │
   │ (Choose Public - it's free and allows Netlify to access)│
   │                                                           │
   │ Initialize this repository with:                        │
   │ ☐ Add a README file          ← DO NOT CHECK THIS       │
   │ ☐ Add .gitignore             ← DO NOT CHECK THIS       │
   │ ☐ Choose a license           ← DO NOT CHECK THIS       │
   └─────────────────────────────────────────────────────────┘

5. Click the green "Create repository" button at the bottom

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
STEP 3: COPY YOUR REPOSITORY URL
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

After creating the repository, you'll see a page with instructions.

1. Look for the section that says:
   "...or push an existing repository from the command line"

2. You'll see a URL that looks like:
   
   https://github.com/YOUR_USERNAME/srinidhi-sarees-website.git
   
   (YOUR_USERNAME will be your actual GitHub username)

3. COPY THIS URL - You'll need it in the next step!

   You can click the copy icon next to it, or:
   - Select the URL
   - Right-click → Copy
   - Or press Ctrl+C

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
STEP 4: PUSH YOUR CODE TO GITHUB
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Now let's upload your code to GitHub!

1. Open PowerShell in this folder:
   C:\Users\LENOVO\Desktop\Srinidhi

2. Run this command (replace YOUR_USERNAME with your GitHub username):

   git remote add origin https://github.com/YOUR_USERNAME/srinidhi-sarees-website.git

   Example:
   git remote add origin https://github.com/srinidhisarees/srinidhi-sarees-website.git

3. Then run:

   git branch -M main

4. Finally run:

   git push -u origin main

5. GitHub will ask for authentication:
   
   Option A - Username and Password:
   - Enter your GitHub username
   - Enter your password
   
   Option B - Personal Access Token (if password doesn't work):
   - Go to: https://github.com/settings/tokens
   - Click "Generate new token (classic)"
   - Give it a name: "Srinidhi Sarees Deploy"
   - Check: ☑ repo (all permissions)
   - Click "Generate token"
   - COPY the token (you won't see it again!)
   - Use this token instead of password

6. Wait for upload to complete (may take 1-2 minutes)

7. ✅ Done! Your code is now on GitHub!

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
STEP 5: VERIFY IT WORKED
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Go back to your browser

2. Refresh the GitHub repository page

3. You should now see all your files listed!

4. ✅ Success! Your repository is ready!

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
WHAT'S NEXT?
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Now that your code is on GitHub, you can:

1. Deploy to Netlify (see DEPLOY_NOW.txt)
2. Share your repository with others
3. Make updates and push them anytime

Your GitHub repository URL:
https://github.com/YOUR_USERNAME/srinidhi-sarees-website

  ❓ TROUBLESHOOTING
═══════════════════════════════════════════════════════════════

Problem: "remote origin already exists"
Solution: Run this first:
   git remote remove origin
   Then try Step 4 again

Problem: Authentication failed
Solution: Use Personal Access Token instead of password
   (See Step 4, Option B)

Problem: Permission denied
Solution: Make sure you're logged into the correct GitHub account
