   git remote add origin https://github.com/YOUR_USERNAME/srinidhi-sarees-website.git

3. Then run:

   git branch -M main

4. Finally run:

   git push -u origin main

5. Enter your GitHub username and password when asked
   (If you have 2FA enabled, use a Personal Access Token instead of password)

6. ✅ Your code is now on GitHub!

3. Authorize Netlify to access your GitHub

4. Click "Add new site" button (green button, top-right)

5. Click "Import an existing project"

6. Click "Deploy with GitHub"

7. Find and click on "srinidhi-sarees-website" repository

8. Netlify will show build settings - they should be:
   
   Build command: npm run build:client
   Publish directory: dist/spa
   Functions directory: netlify/functions
   
   (These are auto-detected from netlify.toml file)

9. Click "Deploy srinidhi-sarees-website" button

10. Wait 2-3 minutes for deployment to complete
    (You'll see a progress bar and build logs)

11. ✅ YOUR SITE IS NOW LIVE! 🎉

12. You'll see a URL like: https://random-name-12345.netlify.app
    Click on it to view your website!
