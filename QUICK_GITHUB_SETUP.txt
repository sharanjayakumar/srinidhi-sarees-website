  🚀 QUICK GITHUB SETUP (You Already Have an Account!)
═══════════════════════════════════════════════════════════════

Since you already have a GitHub account, follow these 3 simple steps:

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
STEP 1: CREATE REPOSITORY ON GITHUB (2 minutes)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Go to: https://github.com

2. Login with your account

3. Click the "+" icon (top-right corner)

4. Click "New repository"

5. Fill in:
   - Repository name: srinidhi-sarees-website
   - Description: E-commerce website for Srinidhi Sarees
   - Visibility: ○ Public (select this)
   - ☐ DO NOT check any boxes below

6. Click "Create repository"

7. You'll see a page with commands - KEEP THIS PAGE OPEN!

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
STEP 2: RUN THE EASY SCRIPT (1 minute)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Open PowerShell in this folder and run:

   .\push-to-github.ps1

The script will ask for your GitHub username - just type it and press Enter!

It will then push your code to GitHub automatically.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
STEP 3: VERIFY (30 seconds)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Go back to GitHub in your browser

2. Refresh the page

3. You should see all your files!

✅ DONE! Your code is on GitHub!

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
ALTERNATIVE: Manual Commands (if script doesn't work)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

If the script doesn't work, run these commands manually:

1. Replace YOUR_USERNAME with your actual GitHub username:

   git remote add origin https://github.com/YOUR_USERNAME/srinidhi-sarees-website.git

2. Then run:

   git branch -M main

3. Finally:

   git push -u origin main

4. Enter your GitHub password when asked
